# 隐私与分享边界

## 三类数据分开保存

| 数据 | 位置 | 是否随程序或阅读档案分享 |
| --- | --- | --- |
| API 密钥 | 当前浏览器页面的内存；请求时发往本机服务，再作为 Bearer 凭据发往所配置的模型服务 | 程序和正常导出的阅读档案不含密钥；刷新后需重新填写 |
| 服务地址、模型名、领域约定、阅读偏好、个人词库 | 浏览器 localStorage | 不含在程序包内；本文使用的术语可随阅读档案导出 |
| PDF、原文、译文、对应关系、阅读位置、批注和解释 | 浏览器 IndexedDB | 不含在程序包内；“导出档案”会包含这些阅读内容 |

应用不创建服务器端账号或在线同步库，不写入 API 请求内容日志，不内置遥测和统计脚本。服务只监听 `127.0.0.1`，检查请求 Host / Origin，并限制可读取的静态文件；不提供文件夹列表或 Git / 凭据文件访问。

这不等同于防御已经控制本机、浏览器扩展或调试工具的攻击者。若在公共电脑上使用，应在离开前关闭页面并清理该站点的数据。

## 哪些操作会发送文字

- **翻译**：发送当前批次的原文、附近上下文、领域和术语约定。
- **测试连接**：发送一次简短的示例请求，可能产生费用。
- **解释难句**：发送所选句子、前后上下文、已有译文和领域说明。

**读取模型列表**仅向配置的服务查询模型目录，携带该服务所需的认证信息与客户端标识，不发送论文、上下文、笔记或术语，也不调用翻译模型。返回的列表不写入浏览器持久存储或阅读档案；关闭设置、切换服务 / 协议 / 密钥后清空，仅保存用户最终选定的模型名称。

请求只发往用户配置的服务；PDF 二进制文件不作为附件上传。模型服务仍会收到上述文字及必要认证信息，其保存与使用方式由供应商决定。本地 Ollama 使用你配置的本机服务地址。

模型请求通过 `User-Agent` 标明 `SentenceReader` 及版本。OpenCode Go 的指定接口还会收到 `x-opencode-session` 随机会话编号：同一篇论文在当前页面内复用，换论文使用不同编号，刷新后重建；编号不含标题、文件名、正文、密钥或设备账号，不写入浏览器持久存储或导出档案。旧页面未提供有效编号时，后端使用当前进程内的随机后备编号。其他模型服务不会收到此会话头。

完整阅读、已有对应关系定位、人工纠正、词库、笔记与图表预览不需要模型请求。自带演示使用预置译文。

HTTP 服务错误若逐字包含当前 API 密钥，应用会将该值替换为遮盖文字后再显示。错误遮盖无法识别所有经过变形、截断或编码的供应商日志；不要把服务后台的原始调试日志作为分享附件。

## 分享程序与分享论文的区别

官方发行包从显式文件清单构建，仅包含程序、说明、自拟示例、第三方组件和可选官方 Python 运行时。它不会读取你的浏览器档案、Cookies、个人模型设置或操作系统凭据。

`.句读.json` 阅读档案另行生成，其中有完整阅读内容，PDF 文档包含完整 PDF。笔记导出也会包含原句、译文和你写下的文字；词库可能包含个人专业用语。不要向笔记、原文或词库中手动粘贴密码后再分享。

## 发布前检查

`scripts/build_release.py` 对发布源文件扫描常见令牌、私钥、持久 API 配置以及开发机路径；只保留指定的自拟演示，并检查压缩包文件名单。发现疑似秘密时只报告文件和规则名，不打印匹配内容。脚本生成的清单带每个分发文件的 SHA-256，便于复核。

自动扫描不是秘密检测的完整保证。新增自定义接口配置、真实论文或截图时，请检查是否含有个人信息；`.gitignore` 只排除未跟踪文件，不能清除已经提交的历史。
