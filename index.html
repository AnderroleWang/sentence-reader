导入已排版对读包

原文与中文 PDF 会按文件中的原始版式显示，点击任一侧的对应区域即可联动高亮。

同时选择一个包中的文件：

  • SideBySide 格式：英文 PDF、中文 PDF、alignment.json。
  • Zotero Bilingual 格式：双语 PDF、对应的 .map.json。中文在左或右均可。

可使用 PDF2zh／BabelDOC 等工具生成中文 PDF，再配合句子坐标映射。只有两份 PDF 时暂不能自动建立对应关系。导入过程在本机完成，不调用翻译服务。

排好版的 PDF 可阅读、重新配对、核对和导出。统一术语时更新舒展阅读中的文字；原 PDF 保留原样。

粘贴网页正文

从论文网页复制英文正文。段落之间保留空行，公式可原样粘贴。

翻译设置

点击翻译或难句解释时，将相应句子及相邻上下文发送到你填写的服务。选用本地模型时，文本留在本机。

填写服务地址与密钥后读取；本地服务通常无需密钥。

编辑译文

从一篇论文开始

  1. 导入可选中文字的 PDF，或粘贴论文网页正文。
  2. 先检查英文识别顺序；PDF 可切换原版和正文。选中有误的单元，用“修正原文”修改。
  3. 在翻译设置填写你的服务地址和模型，再翻译未完成部分。支持分批暂停与续译。
  4. PDF 右侧可选“论文版式”，中文按原来的栏位、标题和段落位置排布，图表、公式和较短的图内标签保留原样。未翻译区域显示英文；原栏位放不下时，点击句子可在可调宽的阅读区看完整译文；选择“舒展阅读”可自然换行连续读全文。跨栏或跨页的句组不按标点硬拆，可展开阅读整组译文。
  5. 点选或拖选英文，中文对应句组同步高亮；点击中文可反向定位。PDF 两侧均可连续滚动，点击对应句子时定位另一侧；页码可直接跳转。按 ↓ / → / J 下一句、↑ / ← / K 上一句，或 Alt+↓ / Alt+↑，在输入框和弹窗中不会触发切句。两侧可一起放大。“专注阅读”会淡化两侧其余内容；“完整阅读”支持调宽和展开。
  6. 使用“对齐检查”查看漏译、数值及已有警告；可重新配对、合并、拆分，并用撤销 / 重做或 Ctrl+Z / Ctrl+Shift+Z 恢复。已排版 PDF 可以重配已有片段。核对后可做确认标记。
  7. “解释难句”会调用你配置的模型，结合相邻上下文解释结构、术语与作者意图，每条附原文依据。AI 解释仍需核对。
  8. “术语”支持悬停释义、自定义本文含义、统一现有译法和个人词库导入 / 导出。“图表 / 公式”可按编号展开原页，关闭后回到当前句。“写批注”自动关联中英文，可导出带原句、译文、页码的笔记。
  9. 阅读位置和文档自动保存在此浏览器。定期导出档案，换浏览器或清理数据前尤其如此。

第一版不支持扫描件 OCR、网页网址直接抓取或短语级精准对齐。复杂表格与公式附近的识别结果需要检查。“已生成”表示编号检查通过，不代表语义已经核对。
