# 更新记录

## 0.4.0

- 原创代码采用 MIT 许可证，补充贡献说明与公开仓库链接。
- 双侧专注高亮、方向键导航与舒适滚动位置。
- 可调宽的完整阅读区与“舒展阅读”全文模式，移除挤在正文中的全文标签。
- 对齐检查，人工重配、互换、合并、拆分与撤销 / 重做。
- 结合上下文解释难句，逐字校验引用依据。
- 术语悬停、统一译法、个人词库导入与导出。
- 图表 / 公式原页预览、已有双语图注与手动页码定位。
- 双语批注，Markdown / JSON 笔记导出。
- Windows x64 便携分发，附快速入门、隐私说明和校验清单。
- 限制本机静态文件访问，阻止读取 Git 元数据、运行时和未列入发布范围的文件。

## 0.3.0

- 两侧 PDF 连续滚动、按需渲染与远处画布释放。
- 精确到字符的点击与拖选定位，减少空白命中和跨行误选。
- 跨页句组、多栏顺序、断词续接及滚动位置恢复改进。
